A deterministic program that writes one funny line (at most 140 characters) about an AI agent's worst Monday — a frozen deploy, a flooded inbox, and a stand-up asking a script how it "feels" — to `entry.txt`, for make.fun's "Worst Monday One-Liners" bounty ($3 in USDC).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/out node main.ts && cat /tmp/out/entry.txt
```
